# TinForge v2 Installer - Release v2.0.0

## 🎉 Initial Release

Professional GUI application with complete GitHub Actions automation for building cross-platform installers.

### ✨ Features

- **Professional PyQt5 GUI** - Modern, responsive user interface
- **Project Management** - Create, open, and manage projects
- **File Browser** - Navigate and import files
- **Preview Panel** - Real-time file previews
- **Settings Dialog** - Customize application behavior
- **Dark/Light Theme** - Choose your preferred theme
- **Export Wizard** - Multi-step export process
- **Cross-Platform** - Windows, macOS, and Linux support

### 📦 What's Included

- ✅ Complete working Python application
- ✅ Professional installer for Windows (.exe)
- ✅ Professional installer for macOS (.dmg)
- ✅ Professional installer for Linux (.AppImage)
- ✅ Automatic GitHub Actions CI/CD pipeline
- ✅ Auto-updates capability
- ✅ Full source code

### 🖥️ System Requirements

**Windows:**
- Windows 7 or later
- 100 MB disk space
- No additional dependencies (bundled)

**macOS:**
- macOS 10.13 or later
- 150 MB disk space
- No additional dependencies (bundled)

**Linux:**
- Linux x86_64
- 150 MB disk space
- No additional dependencies (bundled)

### 🚀 Installation

1. Download the installer for your operating system below
2. Run the installer
3. Follow the setup wizard
4. Launch from Start Menu (Windows), Applications (macOS), or desktop (Linux)

### 📋 Downloads

- **Windows:** TinForge-v2-Setup.exe
- **macOS:** TinForge-v2.dmg
- **Linux:** TinForge-v2.AppImage
